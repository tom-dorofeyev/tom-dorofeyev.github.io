# Working in this repository

Tom Dorofeyev's personal blog, built with Jekyll and hosted on GitHub Pages.

- Articles: [_posts/](./_posts/). Use `YYYY-MM-DD-slug.md` with YAML front matter
  containing `layout: post`, `title`, and a matching `date`.
- Templates: [_layouts/](./_layouts/). Styles: [assets/css/style.css](./assets/css/style.css).
  Images: [assets/images/](./assets/images/). Configuration: [_config.yml](./_config.yml).
- Preserve the author's conversational voice and technical meaning. Do not invent
  experiences, quotations, or publication dates.
- Follow nearby examples. Use Liquid's `relative_url` for internal URLs and
  descriptive alt text for images. The home page lists posts automatically.
- Preserve the existing design, mobile layout, and accessibility unless asked to
  change them. Keep changes focused and compatible with GitHub Pages.
- Do not commit generated files or caches. Commit or push only when requested.
- Check affected content, links, and layouts as appropriate. Report what you
  actually verified and any checks you could not run.
